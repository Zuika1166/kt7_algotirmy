# КТ №7 — Кратчайшие пути

Шесть самостоятельных решений на Java. Каждая задача находится в отдельной папке.

## Запуск

Из папки нужной задачи выполните:

```text
javac Main.java
java Main
```

## Состав проекта

- `task1` — кратчайшие пути в графе с неотрицательными весами.
- `task2` — кратчайшие пути в графе с отрицательными рёбрами без достижимых отрицательных циклов.
- `task3` — ближайший пункт помощи с разрешением ничьих по номеру.
- `task4` — кратчайший маршрут с купоном на одно ребро.
- `task5` — классификация недостижимых вершин, конечных расстояний и вершин с неограниченно уменьшаемой стоимостью.
- `task6` — минимальная стоимость маршрута с ограничением на число рёбер и подсчётом оптимальных маршрутов.
